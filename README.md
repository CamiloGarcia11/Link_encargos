# Encargos Mi Ángel — Official Link-in-Bio & Brand Hub

Aplicación web oficial tipo "Link-in-Bio / Linktree" de alto impacto visual para la marca **Encargos Mi Ángel**, con arquitectura **Desktop-First / Full Responsive**, micro-interacciones hápticas, efectos de brillo spotlight y diseño boutique champaña/oro.

---

## 🌟 Características Principales

* **Desktop-First & 100% Responsive:** En pantallas de escritorio (`>= 1024px`) ofrece un layout dual-pane con tarjeta de presentación boutique, métricas de confianza y código QR interactivo para continuidad móvil. En dispositivos móviles se adapta como un Link-in-Bio táctil y fluido.
* **Enlaces Inmediatos (Above-the-Fold):** Proporciones ajustadas para que el catálogo oficial y los enlaces de atención rápida sean visibles apenas el usuario abre la web sin necesidad de desplazarse.
* **Micro-interacciones y UI Avanzada:**
  * Efecto **Spotlight Border** que sigue el cursor del mouse en computadoras.
  * Shimmer wave y glowing badge para el CTA destacado del Catálogo Oficial.
  * Ráfagas de confeti personalizadas con la paleta de la marca al hacer clic.
  * Micro-sonidos armónicos sintetizados con Web Audio API (con switch de silenciado).
  * Modal interactivo para compartir y escanear QR.
* **Branding de Lujo:**
  * Tipografías oficiales: `Quicksand` (display) y `Nunito` (body).
  * Paleta de colores boutique: Amarillo Pastel (`#FEF9C3`), Oro Champaña (`#D4AF37`) y Obsidiana (`#171717`).
  * Logo oficial integrado en avatar, watermark animado y generador QR.

## 🛠️ Stack Tecnológico

* **Framework:** Next.js 15 (App Router)
* **Librería UI:** React 19 & TypeScript
* **Estilos:** Tailwind CSS 3.4
* **Animaciones:** Framer Motion
* **Iconografía:** Lucide React & React Icons
* **Efectos:** Canvas Confetti & Web Audio API

## 🚀 Despliegue en Vercel

1. Inicia sesión en [Vercel](https://vercel.com).
2. Haz clic en **Add New...** > **Project**.
3. Importa el repositorio de GitHub: `CamiloGarcia11/Link_encargos`.
4. Vercel detectará automáticamente Next.js. Deja los ajustes por defecto y haz clic en **Deploy**.
5. ¡Tu aplicación estará en línea con SSL automático y CDN global en menos de 1 minuto!
